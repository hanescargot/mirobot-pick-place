## Learned

### Virtual environment (venv)
- Project마다 isolated된 Python workspace를 만드는 tool
- 이유: library version conflict 방지, system Python 보호, **reproducibility**
- `pip freeze > requirements.txt`로 dependency를 고정하면 누구나 같은 environment를 재현 가능
- `.venv/` folder는 Git에 올리지 않고 `.gitignore`에 추가
- Analogy: recipe마다 따로 만든 meal kit box

### venv vs Docker
| | venv | Docker |
|---|---|---|
| Isolation scope | Python library만 | OS + system package + library 전체 |
| Weight | Lightweight | Heavy |
| Hardware access (USB, webcam) | Easy | macOS에서 까다로움 |

→ 이번 project는 hardware에 직접 access해야 해서 venv 선택. Deployment나 simulation 단계라면 Docker 고려.

### PC ↔ Robot connection
- USB 연결 시 robot 안의 **CH340 chip**이 USB를 **serial port**로 변환
- macOS에서는 `/dev/cu.usbserial-xxxx` 형태로 보임
- 연결에 필요한 건 **power + USB**뿐 (Bluetooth 불필요)

### Pose
- 첫 move 결과: `set_tool_pose(200, 20, 230)` → `Pose(x=200.01, y=20.004, z=229.704, roll=0.0, pitch=0.0, yaw=0.0)`
- x, y, z = position (mm), roll, pitch, yaw = orientation (rotation)
- Position 3 + rotation 3 = **6-DoF (Degrees of Freedom)**
- Base frame origin: base center / x-axis 앞쪽, y-axis 왼쪽, z-axis 위쪽 (official manual 기준)
- z error 약 0.3mm: coordinate → joint angle (IK) → motor step rounding → joint angle → coordinate (FK) 과정에서 발생

### Homing
- 각 joint를 reference position으로 보내서 robot이 현재 angle을 알게 하는 과정
- 매번 시작할 때 필수. 안 하면 coordinate가 틀어짐

## Troubleshooting
1. **`python -m venv` 실패: No module named venv**
   - Cause: macOS의 `python` command가 Python 2.7을 가리킴 (PATH 문제)
   - Fix: `python3`로 virtual environment 생성
2. **SDK import error: `ValueError: mutable default ... use default_factory`**
   - Cause: `wlkata-mirobot-python` 0.1.14가 dataclass default value로 object를 사용. Python 3.11부터 이런 code를 금지 (모든 instance가 같은 object를 share하는 bug 방지)
   - Fix: Python 3.9.6 (system Python)으로 virtual environment 재생성
3. **Port auto-detection 실패**
   - Cause: SDK가 Mac의 Bluetooth port (`/dev/cu.BLTH`)를 robot으로 착각
   - Fix: USB port (`/dev/cu.usbserial-14410`)를 code에 직접 지정
   - Improvement: port name 대신 USB device ID (CH340 VID `0x1A86`)로 찾는 `find_mirobot_port()` 작성
